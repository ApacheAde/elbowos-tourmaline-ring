# Tourmaline Ring

Full-colour Python 3 neon rotating-paddle arcade for [ElbowOS](https://x.com/ElbowOS).

Coloured shards fall inward toward a pulsing core. Spin the four-paddle ring with **A / D** or the arrow keys and smash them before they hit the heart.

## Run

```bash
pip install -r requirements.txt
python3 tourmaline_ring.py --play
```

Headless 9:16 reel (15s, 1080×1920, H.264):

```bash
python3 tourmaline_ring.py --record --out TOURMALINE_RING_ElbowOS.mp4
```
